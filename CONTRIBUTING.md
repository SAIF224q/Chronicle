# Contributing to Chronicle

Thank you for your interest in contributing to Chronicle. Contributions help improve the app and support a stronger community.

## How to contribute

1. Open an issue first if you want to report a bug, request a feature, or discuss a design change.
2. Fork the repository and create a branch for your work:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. Make your changes in a clear, incremental way.
4. Add tests or verify existing functionality where appropriate.
5. Ensure the code follows the repository's conventions and formatting.
6. Commit with a descriptive message and push your branch.
7. Open a pull request with a concise summary of your changes and any relevant context.

## Notes

- Keep changes focused and small when possible.
- If your change affects app behavior, include a short description of how to validate it.
- Use the Flutter tooling to verify the app builds successfully:
  ```bash
  flutter pub get
  flutter analyze
  flutter test
  ```
